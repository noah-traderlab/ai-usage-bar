AI Usage Bar — Mac 用チーム参加ツール 0.1.0

これは、Mac の人が「AI Usage Bar」のチームに参加して、自分の Claude Code・Codex の
利用量をマスター（管理者）に共有するためのツールです。
マスターの管理画面は Windows 版が担当します。このツールは「参加」と「報告」を行います。

────────────────────────────────
必要なもの
────────────────────────────────
・macOS（標準の Python 3 を使います。追加インストールは不要です）
  ※「python3」が見つからない場合は、ターミナルで  xcode-select --install  を実行してください。
・マスターから届いた「招待メール（招待コード付き）」
・マスターと共有しているフォルダ（Google ドライブ / OneDrive / 社内ファイルサーバー等）が
  この Mac に同期されていること

────────────────────────────────
使い方（画面）
────────────────────────────────
1.「AI-Usage-Bar-参加.command」をダブルクリックします。
   ※初回に「開けません（開発元を確認できない）」と出たら、Control キーを押しながらクリック →
     「開く」を選ぶか、システム設定 → プライバシーとセキュリティ →「このまま開く」を押します。
2. 届いた招待メールの本文を、まるごと貼り付けます（共有フォルダとチーム確認コードが自動で入ります）。
   ※共有フォルダの場所が違う場合は、「参照…」でこの Mac の同じフォルダを選んでください。
3.「読み込む」を押し、チーム確認コードがマスターから聞いたものと一致することを確認します。
4. 名前・メールアドレス（Claude Code・Codex にログインしているもの）を確認します。
5.「上記のすべてを共有することに同意します」にチェックし、「参加する」を押します。
6. 参加後は、この画面を開いている間、自動で報告します（変更があったとき・最短5分ごと）。

共有される内容：
  PC名・ユーザー名・メールアドレス、利用量（トークン数・残り枠・日別・モデル別）、
  セッションのタイトル・作業フォルダ・時間帯、Claude Code・Codex に入力した依頼文の本文（直近14日）
  ※ ChatGPT・Claude の通常チャットは含みません。報告は暗号化され、マスター以外は読めません。

やめるとき：画面の「チームから抜ける」を押すと、共有フォルダのこの Mac の報告を削除します。

────────────────────────────────
使い方（ターミナル：画面が使えないとき・自動化）
────────────────────────────────
フォルダ内で、次のように実行します（招待メールをファイルに保存して渡せます）。

  # 参加（同意して参加する場合は --yes を付けます）
  python3 -m aiusagebar join --invite 招待メール.txt --email あなた@example.com --yes

  # 今すぐ報告 / 状態表示 / 常駐して定期報告 / 退出
  python3 -m aiusagebar report
  python3 -m aiusagebar status
  python3 -m aiusagebar watch
  python3 -m aiusagebar leave

  # watch 中にリセット通知も出す（0:しない 1:残りが少なかったときだけ 2:毎回）
  python3 -m aiusagebar watch --reset 1 --threshold 20

────────────────────────────────
フレンドの残り枠（任意・既定オフ）
────────────────────────────────
チームとは別に、共有フォルダ（OneDrive など）を通じて、友だち・同僚と「残り枠だけ」を
見せ合える機能です。共有するのは表示名・残り％・リセット時刻だけで、メールアドレス・
トークン数・作業内容は共有しません。Windows 版のフレンドとも同じ形式なので、相手が
Windows でも Mac でも見せ合えます。

  # フレンドをオンにする（共有フォルダを指定。招待コード AIUB-FRIEND-1: でも可）
  python3 -m aiusagebar friends on --folder "/Users/あなた/OneDrive/AI残り枠共有" --name 太郎
  # 今のフレンド一覧を見る
  python3 -m aiusagebar friends show
  # やめる（共有フォルダから自分のファイルを消します）
  python3 -m aiusagebar friends off

オンにしたあと「python3 -m aiusagebar watch」を実行しておくと、定期的に自分の残り枠を
公開し、フレンドの残り枠を読みます（チームに参加していなくても使えます）。

────────────────────────────────
リセット通知（既定オフ）
────────────────────────────────
利用枠がリセットされたら、macOS の通知でお知らせします（watch 中に判定）。
「残りが少なかったときだけ」か「毎回」を選べます（--reset 1 または 2）。

────────────────────────────────
保存先・プライバシー
────────────────────────────────
・参加情報とこの Mac の鍵は  ~/Library/Application Support/AIUsageBar  に、
  本人だけが読める権限（600）で保存します。
・このツールはインターネットに接続しません。読み書きするのは共有フォルダだけです。
・Claude Code（~/.claude/projects）・Codex（~/.codex/sessions）の標準の記録を読み取ります。

────────────────────────────────
Windows 版との一致について
────────────────────────────────
暗号化・署名・報告の形式・トークンの集計方法は Windows 版と同一で、相互に検証済みです
（相互検証テスト30項目に合格。フレンドの残り枠ファイルも Windows と相互に読み書きできることを確認）。
マスター（Windows）は、この Mac からの報告をそのまま集計できます。
