# Third-party components and asset review

This source snapshot contains no bundled Python interpreter, .NET runtime, font files, or third-party dependency packages. Windows uses the installed .NET Framework and operating-system APIs. The Mac tool uses Python standard-library modules, including Tkinter when available. These runtimes remain subject to their own terms and are not relicensed by this project.

The source review found no third-party copyright or license headers. The creator confirmed authorship of the code and documentation and approved publication under MIT on 2026-10-23. The review itself is not an exhaustive external similarity or ownership audit.

The original `assets/AppIcon.ico` and its conversion script were omitted from this public-preparation snapshot because the source artwork and its permission to redistribute could not be established. The application can be built without a custom embedded icon. Task-tray graphics are drawn by the application; font files are not distributed.
