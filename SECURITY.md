# Security policy

## Reporting a vulnerability

Please use this repository's **Security → Report a vulnerability** feature to report a suspected issue privately. If that option is unavailable, do not put vulnerability details, credentials, private logs, or personal information in a public Issue. Wait for the maintainer to provide a private reporting channel.

Include the affected version or commit, platform, expected and actual behavior, the security boundary affected, and a minimal reproduction using synthetic data. Distinguish observed impact from hypothetical consequences. AI-assisted analysis is welcome when disclosed and independently reproducible.

There is no paid bug-bounty program or guaranteed response deadline. Publication, researcher credit, and any CVE request are coordinated after the issue is assessed. A report or patch does not automatically qualify for a CVE or a third-party verification program.

## Supported versions

This is an early-stage project. Maintenance currently targets the latest source revision. Binary distributions and older versions must be checked separately against the source revision they contain.
