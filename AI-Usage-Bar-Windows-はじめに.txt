AI Usage Bar 0.1.0（Windows版）— テスト配布版

対応：Windows 10 / 11
必要なもの：.NET Framework 4.7.2 以上（Windows 10/11 には標準で入っています。古い場合は起動時に案内します）
実機確認：Windows 11 Home（26200）。Windows 10 での実機確認は未実施です。
詳しい仕様とセキュリティ情報は「仕様書・セキュリティ資料.md」をご覧ください。

・AI-Usage-Bar-Setup-0.1.0.exe … インストーラー（ソフト本体・アンインストーラーを含む）
・はじめに.txt … この説明書
・製品カタログ.md／.html … 製品紹介

【この配布版について】
コード署名は行っていません。インターネット経由で受け取ったファイルは、
起動時に「WindowsによってPCが保護されました」と表示されることがあります。
配布元が確かな場合のみ「詳細情報」→「実行」で起動してください。
受け取ったら、PowerShell で次を実行し、SHA256.txt の値と一致するか確認できます。
  Get-FileHash .\AI-Usage-Bar-Setup-0.1.0.exe -Algorithm SHA256
一般配布用の認証済み完成版ではありません。

【インストール】
1. AI-Usage-Bar-Setup-0.1.0.exe をダブルクリックします（管理者権限は不要）。
   Slack などで受け取った場合は、zip をいったんPCにダウンロードし、右クリック →「すべて展開」
   してからインストーラーを実行してください。
2. 画面の案内に沿って「インストール」を押すと、%LOCALAPPDATA%\Programs\AI Usage Bar\ に
   インストールされ、スタートメニューに登録されます。デスクトップのショートカットや
   ログイン時起動は、インストール時のオプションで選べます。
3. スタートメニューまたはタスクバーのボタンから起動します。
・無音インストール（配布ツール等）：AI-Usage-Bar-Setup-0.1.0.exe /quiet
・アンインストール：「アプリと機能」から、またはスタートメニューのアンインストーラーで。
  設定・データも消す場合は /removedata を付けて実行します。
・更新：新しいインストーラーを実行すると、起動中でも安全に入れ替わります。

【タスクバーに並べる（ピン留め）】
起動すると、画面は開かずにタスクバーへ収納されます。
タスクバーのボタンには、上段にCodex、下段にClaudeの残り％が表示されます。
・ボタンをクリック：画面を開く／もう一度クリックで収納
・ボタンを右クリック →「タスクバーにピン留めする」：いつでも起動できるよう固定
・画面右上の「–」やEscキーでも収納されます（アプリは終了しません）
設定で「タスクバーに表示」をオフにすると、タスクトレイから開くポップアップ方式になります。
設定の「起動時はタスクバーに収納」をオフにすると、起動時に画面を開きます。

【タスクトレイのアイコン】
画面右下のタスクトレイにも、Codex（角丸の四角）とClaude（丸）のアイコンが出ます。
Windows 11 では最初「^」の中に隠れています。常に表示したい場合は、
アイコンを「^」の外へドラッグするか、
設定 → 個人用設定 → タスクバー → その他のシステム トレイ アイコン で
「AI Usage Bar」をオンにしてください。

【事前に必要なもの】
本アプリにChatGPT、Codex、Claude、Claude Codeは含まれません。
利用するサービスのアプリ・CLIを、ご自身のPCに用意してください。
・Codexの残り枠：CodexアプリまたはCodex CLIをインストールし、本人のChatGPTアカウントでログイン。
  検出先は PATH（絶対パスの項目のみ）、%USERPROFILE%\.local\bin、npm（%APPDATA%\npm）、
  Codexアプリ同梱のCLI（%LOCALAPPDATA%\OpenAI\Codex\bin）です。
・Claudeの共有枠：Claude Desktopで本人のアカウントにログインし、使用状況を確認。
  通常版（%APPDATA%\Claude）とMicrosoft Store版の両方に対応しています。
・Claude Codeの履歴：このPCの %USERPROFILE%\.claude\projects にある標準履歴を読み取ります。
・Codexの作業ログ：このPCの %USERPROFILE%\.codex\sessions にある標準履歴を読み取ります。
  保存先を変更している場合は対象外です（CODEX_HOME の指定には対応）。
すべてを利用していなくても、取得できる項目だけ表示します。

【使い方】
画面は「利用枠」「履歴」「詳細ログ」「チーム」「設定」の5つのタブです。
数字は、5時間・週間のうち最も少ない残り割合です。
緑：20%超、橙：20%以下、赤：10%以下、灰＋「—」：未取得・古い情報。
通知とログイン時起動は初期状態ではOFFです。
「設定」タブの「枠がリセットされたら通知」で、リセットの通知も選べます（しない／残りが少なかったときだけ／毎回）。Codexはリセット時刻を過ぎたとき、Claudeは残りが大きく戻ったとき（保存履歴は約15分ごと）に知らせます。

【更新間隔】
設定画面で、次の2つを別々に選べます（どちらも 1／5／10／15／30／60分）。
・Codexの更新間隔（初期値5分）：Codex CLI を起動して利用状況を取得します。生成リクエストは送りません。
・Claude・作業ログの確認間隔（初期値1分）：Claudeの利用枠と、Claude Code・Codexの記録を
  PC内のファイルから読みます（通信しません）。
Claudeの利用枠は Claude Desktop が約15分ごとに記録するため、間隔を短くしてもそれより新しくはなりません。
保存履歴は15分（確認間隔を長くした場合はその分を加えた時間）を超えると古い情報になります。
本アプリの更新ボタンだけではClaude側の保存履歴は新しくなりません。

【詳細ログ（AIで何をしていたか）】
「詳細ログ」タブで、日付ごとに次の内容を一覧できます（直近7日分）。
・セッション別：タイトル、作業フォルダ、時間帯、入力経路、モデル、
  トークン内訳、サブエージェントの数。クリックで詳細と「この日の入力」を表示。
・入力の一覧（誰が・何を）：入力した日時、入力の種類、入力者、アカウント、依頼文。
  - 入力者：このPCのWindowsユーザー名とPC名
  - アカウント：Claude Code・Codexにログイン中のアカウント（メールアドレス）
  - 入力の種類：本人の入力／他のプログラム経由／自動実行／AIが入力（サブエージェント）
  - 入力経路：Claudeアプリ、ターミナル（CLI）、Codexアプリ、codex exec など
  作業中に追加で送ったメッセージも「本人の入力」として含まれます。
トークン内訳：
・Claude Code：入力、出力、キャッシュ読み取り、キャッシュ作成
  （同じ応答はメッセージIDとリクエストIDで重複を除きます）
・Codex：入力（うちキャッシュ）、出力（うち推論）、合計
  （同じ応答は応答IDで重複を除きます。古い形式の記録は累計から推定し「推定」と表示）
「書き出す…」で、その日または7日間を Markdown / CSV で保存できます。
書き出しは、Excelで数式として実行されたり、HTMLとして表示されたりしないよう無害化しています。
設定で「依頼文を表示」をオフにすると、一覧と書き出しに依頼文やタイトルを含めません。
「詳細ログを表示」をオフにすると、詳細ログタブを使いません。

【チーム機能（マスター／一般ユーザー）】
導入した人（マスター）が、メンバーをメールアドレスで登録し、各メンバーのAI利用量・費用・
作業内容・依頼文を表で確認できます。一般ユーザーは自分の分だけを見られます。
データは社内の共有フォルダ（ファイルサーバー、OneDrive / SharePoint の同期フォルダなど）に
暗号化して置きます。本アプリ自身はインターネットに接続しません。

■ マスター（最初に1人）
1. 「チーム」タブ →「チームを作成する（マスターになる）」
2. チーム名、共有フォルダ、あなたの名前・メールアドレス、パスフレーズ（12文字以上・6種類以上の文字）を入力
3. 表示された「チーム確認コード」（32桁）と共有フォルダの場所を、メンバーに伝える
   （確認コードは対面・電話・社内チャットなど、共有フォルダとは別の方法で伝えてください。
    パスフレーズは安全な場所に保管。メンバーには伝えません）
4. 「メンバーを追加（メール）」で、参加してほしい人のメールアドレスを入力（1行に1人。名前付きや
   Excel・Slack からの貼り付けも可）。閲覧範囲は初期値「依頼文まで」
5. 続けて出る「招待を送る」画面で招待メールを送ります
   ・「メールで送信」：このアプリから直接送信します（初回だけ「送信設定…」で、あなたのメールアドレスと
     送信用パスワードを設定。Gmail・Outlook は2段階認証の「アプリパスワード」が必要です。
     パスワードはこのPCの本人だけが読める形で保存され、外部には送りません）
   ・「メールアプリで作成」「Gmail で作成」：宛先・件名・本文を入れた作成画面を開くだけ（送信はご自身で）
   ・Slack で送る場合は「コピー」
   ※メール本文は簡素で、「参加リンク」と「招待コード」が入ります。受け取った人が参加リンクを開くと
     （AI Usage Bar が入っているPCでは）参加画面が開き、共有するかどうかを選べます。
     リンクが使えない場合は、招待コードを「チームに参加する」に貼り付けてもらいます。
6. 相手が参加すると、登録メールで Claude Code・Codex にログインしているPCは自動で集計されます
   （承認操作は不要。鍵やメールが変わったPC、ログインしていないPCは「確認する」で承認します）
・自動集計をやめたい場合は「チーム設定」で切り替えられます（その場合は承認が必要）
・閲覧範囲は「利用量のみ」「作業の概要まで」「依頼文まで」の3段階。本人が同意した範囲までしか届きません
・他の人をマスターにする：メンバーを編集して権限を「マスター」にし、本人のPCで
  「マスター権限を有効にする」→ パスフレーズを入力してもらう
・マスターを外す・削除するときは、管理画面の「マスターを外す（鍵を更新）」を使います
  （外された人が以後の報告を読めないよう、同時に新しいパスフレーズを設定します）
・「単価・為替」で API 換算の単価（Claude は公式料金を初期設定、Codex は未設定）と為替を設定できます
・契約プラン・月額・メモは暗号化して保存され、マスターだけが読めます
・表や依頼文は CSV で保存できます（依頼文のCSVは暗号化されないため、保存先に注意）
・「ダッシュボード（上層部向け）」→「AIに提案してもらう」で、集計サマリーから
  現状サマリーと次の一手を Claude が自動作成します（任意・既定オフ。マスターのAPIキーが必要）。
・「ダッシュボード（上層部向け）」→「定期レポート…」で、毎日／毎週（曜日指定）／毎月・時刻（時：分）を
  決めておくと、上の提案を自動生成してタスクトレイに通知します（任意・既定オフ。クリックで開けます）。
・「ダッシュボード（上層部向け）」→「スタートライン…」で、顧客のAI導入段階（導入前／試験導入／一部活用／
  全社活用）に合わせた目標を設定できます。KPI・ランキング・サマリーが目標に対する達成度で表示されます
  （任意・既定オフ。設定はこのPCだけに保存し、メンバーには共有しません）。
・「ダッシュボード（上層部向け）」で、AI活用ダッシュボードを開けます
  （活用率・AI力ランキング・「サマリー・次の一手」・日別トークン・API換算コストを1画面で表示。
   誰が使いこなしているか／未活用は誰か／次に何をすべきかの気づきを、取得済みデータから提示）

■ 一般ユーザー
1. 「チーム」タブ →「チームに参加する（一般ユーザー）」
2. マスターから届いた招待メールの本文を、まるごと貼り付け（共有フォルダとチーム確認コードが自動で入ります）
   ※共有フォルダの場所が違う場合は「参照…」でこのPCの同じフォルダを選んで「読み込む」
3. チーム確認コードがマスターから聞いたものと一致することを確認
4. 名前・メールアドレス（Claude・Codex にログインしているもの）を確認し、
   「上記のすべて（依頼文の本文を含む）をマスターに共有することに同意します」にチェックして参加
   （同意しないと参加できません。会社のポリシーで制限された項目は共有されません）
・以後、内容が変わったときに自動で報告します（最短5分ごと）。共有中の範囲は「チーム」タブに常に表示されます
・共有をやめるときは「チームから抜ける」を選ぶと、共有フォルダの報告をすぐに削除します

■ Mac の人が参加する場合
・同梱の「Mac用チーム参加ツール」フォルダを Mac にコピーし、「AI-Usage-Bar-参加.command」を
  ダブルクリックします（Mac 標準の Python で動きます。追加インストール不要）。
  詳しくは同フォルダ内の「はじめに（Mac）.txt」をご覧ください。
・マスターの管理画面は Windows 版が担当します（Mac は参加・報告のほか、フレンドの残り枠・リセット通知にも対応）。

■ 費用の見方
・プラン月額：マスターが登録した契約プランの月額（実際の費用）
・API換算（目安）：使ったトークン数を API 料金に換算した参考値。サブスクリプションの請求額とは異なります

【フレンドの残り枠（友だち同士で見せ合う）】
フレンドと Claude・Codex の残り枠を見せ合えます（チーム機能とは別で、マスターはいません）。
1. OneDrive・Googleドライブ・Dropbox などで、フレンドとフォルダを共有しておく
2. 「利用枠」タブ下の「フレンドの残り枠」→「フレンド機能を設定する…」
3. 共有フォルダと表示名を選んで「保存」。表示された招待コード（AIUB-FRIEND-1:…）をフレンドに送る
4. フレンドは同じ画面の「招待コード」に貼り付けて保存（フォルダの場所が違う場合は自分で選び直す）
・共有するのは「表示名」「残り％」「Codexのリセット時刻」「更新時刻」だけ。メールアドレス・トークン数・作業内容・依頼文は共有しません
・30分以上更新がないフレンドは灰色で「更新なし」と表示します
・やめるときは設定で「自分の残り枠をフレンドに見せる」をオフにすると、共有フォルダから自分のファイルを削除します
・アプリ自体は通信しません（共有フォルダに小さなファイルを書き、読むだけ）

【表示の範囲】
Codex：残り枠、リセット日時、モデル別の枠、サービスが返す日別トークン履歴、
       このPCのセッション記録から集計したトークン内訳。
Claude：通常チャット・Claude Codeの共有利用枠（5時間・週間）。
Claude Code：このPCの直近7日分のトークン履歴（キャッシュを含む）。
ChatGPT・Claudeの通常チャットは履歴がPCに残らないため、作業ログの対象外です。
ChatGPT通常チャットの残り枠・個別トークン数、Claude通常チャット単独の
トークン数、Claudeのリセット日時・モデル別枠は未対応です。
アカウントは「現在ログイン中の情報」です。過去に別アカウントで使った記録は区別できない場合があります。
Claude Desktop内部保存形式の変更やCodex CLIのバージョンにより、
取得できなくなる場合があります。API利用を請求額へ換算する機能はありません。

【データの扱い・セキュリティ】
・本アプリは既定ではインターネットに接続しません（テレメトリ・自動更新なし）。
  例外は、マスターが任意で有効にする「AI提案」機能だけです（マスターのAPIキーで、
  ダッシュボードの集計サマリーを Anthropic API に送信。依頼文の本文は送りません。
  ポリシー DisableAiSuggest=1 で禁止できます）。
  Codexの利用状況は、Codex CLI が利用者のログイン情報で取得します。
・配布ファイルに作成者の利用履歴、アカウント、認証情報は含めていません。
・集計キャッシュの保存先は %LOCALAPPDATA%\AIUsageBar です。
  このフォルダは本人・SYSTEM・Administrators だけが読めるように設定されます。
・保存するのは、トークン使用量、取得時刻、セッションID、作業フォルダのパス、ログ内の位置、
  依頼文のHMAC（重複判定用。端末ごとの鍵で作り、元の文には戻せません）です。
  会話本文・認証情報・メールアドレスは保存しません（依頼文は表示するときにログから読み取ります）。
・依頼文がファイルに保存されるのは「書き出す…」で自分で保存したときだけです。
  書き出したファイルには依頼文やアカウントが含まれるため、共有するときはご注意ください。
・設定 →「仕様・セキュリティ情報を書き出す…」で、その端末での実際の値
  （exeのハッシュ、読み書きする場所、通信、起動する子プロセス、組織ポリシーの状態）を保存できます。

【企業で導入する場合（管理者向け）】
グループポリシーや Intune で次のレジストリ値（DWORD、1で有効）を配布すると、
利用者が設定で解除できない形で機能を制限できます。
  キー：HKLM\SOFTWARE\Policies\AIUsageBar（または HKCU\SOFTWARE\Policies\AIUsageBar）
  DisableActivityLog          … 詳細ログを無効（作業フォルダ・依頼文の位置も保存しない）
  HidePromptText              … 依頼文・タイトルを表示・書き出ししない
  DisableExport               … 書き出しを禁止
  DisableCodexFetch           … Codex CLI を起動しない
  DisableStartupRegistration  … ログイン時起動を禁止
  DisableTeamSharing          … チーム機能（共有フォルダへの報告・マスター機能）を禁止
  DisableFriends              … フレンドの残り枠（共有フォルダでの見せ合い）を禁止
  TeamMaxScope（0／1／2）     … チームに共有できる範囲の上限（0：利用量のみ、1：作業の概要まで、2：依頼文まで）
詳しくは「仕様書・セキュリティ資料.md」の「7.2 組織ポリシー」「7A. チーム機能」をご覧ください。
依頼文まで共有する場合は、利用目的・閲覧者・保存期間を社内規程で定め、対象者に事前に周知してください。

【アンインストール】
チームに参加している場合は、「チーム」タブの「チームから抜ける」で報告を削除してください。
設定でログイン時起動を有効にしている場合はOFFにし、画面下の「終了」で終了。
タスクバーにピン留めしている場合は、右クリック →「タスクバーからピン留めを外す」。
exeファイルを削除します（推奨の場所へ移動した場合は %LOCALAPPDATA%\Programs\AI Usage Bar も）。
集計キャッシュは残るため、不要な場合は %LOCALAPPDATA%\AIUsageBar を削除してください。
元のCodex・Claudeの設定や履歴を削除する必要はありません。
