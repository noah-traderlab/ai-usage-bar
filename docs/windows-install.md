# AI Usage Bar Windows 0.1.0

ZIPを展開し、AI-Usage-Bar-Setup-0.1.0.exeを起動します。Windowsの.NET Framework 4.8を前提に公開ソースからビルドしています。Windowsの管理者向け画面とチーム参加・報告機能を含みます。Mac用アプリは別配布です。

インストーラーは現在のユーザーのLocalAppData配下へインストールし、スタートメニューとアンインストール項目を登録します。管理者権限は不要です。自動起動・共有内容を確認して選択してください。

このバイナリにはAuthenticode署名がありません。Windowsや組織の保護機能によりブロックされる可能性があります。署名済み製品や外部セキュリティ監査済みとは扱わないでください。保護設定を無効化する手順は提供しません。

チーム参加時は共有内容への同意が必要です。PC名・ユーザー名・メール、使用量、セッションタイトル・作業フォルダ・時間帯、直近14日の入力本文を管理者へ報告する機能があります。共有先と範囲を確認して使用してください。

同梱SOURCE.txtがビルド元の公開コミットを示します。SHA256SUMS.txtでインストーラーを確認できます。MITライセンスと第三者の注意事項も同梱しています。旧配布ZIPの未確認画像・修正前Macソースは含めていません。
