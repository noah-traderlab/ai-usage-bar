# Macアプリ版

Pythonの準備やpip操作なしで使える、Mac用のチーム参加・報告アプリです。管理者画面はWindows版を使います。PyPI版も引き続き利用できます。

## インストール

Apple Silicon（M1以降）はarm64、Intel Macはx86_64のDMGを選びます。DMGを開き、AI Usage Bar.appをApplicationsへドラッグし、アプリケーションフォルダから起動します。終了後はDMGを取り出せます。削除する場合はアプリをゴミ箱へ移動します。チーム参加を停止するには先にアプリ内で退出してください。

現段階のビルドは開発用のアドホック署名です。Apple Developer ID署名・公証は未実施で、ダウンロードしたアプリはGatekeeperによりブロックされる可能性があります。通常配布用の署名・公証が完了するまで、警告を回避して起動することを前提にしないでください。実利用端末でのGUI操作は別途確認が必要です。

参加時には共有内容を確認して同意します。報告にはPC名・ユーザー名・メール、使用量、セッションタイトル・作業フォルダ・時間帯、直近14日の入力本文を含みます。起動だけで新しいチームへ自動参加することはありません。参加後はアプリを開いている間に報告します。ログイン時の自動起動は登録しません。

## ビルド検証

GitHub ActionsでApple Silicon / Intel別にPythonとTcl/Tkを同梱します。既存テスト、バンドル署名整合性、同梱Tkのウィンドウ生成・終了、DMG整合性、SHA256を検査します。smoke-testは利用者のログ・チーム状態を読みません。通常のGUI操作全体の検証やApple公証とは別です。

Developer ID署名・公証には所有者のApple Developerアカウントと署名資格情報の設定が必要です。秘密鍵やパスワードをIssueやチャットへ貼り付けないでください。
