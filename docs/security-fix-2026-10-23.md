# Mac状態ファイル保存処理の改善（公開前ドラフト）

対象: `mac/aiusagebar/team.py` の `_write_atomic` と `_write_private`。

従来の実装では置換失敗時に一時ファイルが残りました。状態ファイルにはメンバー秘密鍵が含まれるため、不要な秘密のコピーを残さないよう、成功・失敗の両方で後始末を行います。

従来の一時名が既存ファイルと衝突した場合、そのファイルを切り詰めていました。排他的な一時ファイル作成へ変更しました。

再現は模擬データと失敗注入で実施しました。実際の他ユーザーによる秘密の取得や、乱数名の予測攻撃は実証していません。POSIXでは作成時から0600になりますが、今回のテスト実行環境はWindowsで、Mac実機での確認は未完了です。

修正前は4サブケース失敗、修正後は追加3テストメソッド成功。既存selftestも36チェック成功。調査と実装はAI支援によるものです。

配布者からWindows版とMac版を他の2人へ配布した旨の申告があります。配布日・版番号・配布物と影響コードの一致は確認中です。本稿は第三者受理済みアドバイザリやCVE取得を意味しません。
