# AI Usage Bar — 製品カタログ

**Claude Code と Codex の利用状況を、チームでまとめて把握する Windows 用ツール**

バージョン 0.1.0（Windows 版）／ 2026年9月

---

## 1. これは何か

AI Usage Bar は、**Claude Code・Codex（ChatGPT）の残り利用枠とトークン使用量を、タスクバーでひと目で確認できる**デスクトップアプリです。個人での使いすぎ防止から、チーム全体の利用量・費用の見える化までを、1つのアプリでカバーします。

- **個人向け**：あと何回使えるか（残り枠）と、今日・今週どれだけ使ったかを常に表示。
- **チーム向け**：管理者（マスター）が、メンバーの利用量・費用・作業内容を1つの表で確認。

アプリ自身は**既定ではインターネットに接続しません**。PC 内の記録を読むだけで、チーム機能で使うのも社内の共有フォルダだけです（唯一の例外は、上層部向けに任意で有効化する「AI提案」機能。マスターのAPIキーで集計サマリーだけを送信します）。

---

## 2. こんな課題を解決します

| よくある悩み | AI Usage Bar でどうなるか |
|---|---|
| 「気づいたら Claude / Codex の枠を使い切っていた」 | タスクバーに残り％を常時表示。少なくなったら通知 |
| 「チームで毎月いくら AI に使っているのか分からない」 | メンバーごとの利用量・API換算の金額・プラン月額を一覧表示 |
| 「誰がどれくらい AI を使い、何を頼んでいるのか把握できない」 | 日別・モデル別・セッション別・依頼文までを、同意の範囲で確認 |
| 「AI ツールの利用を、情シスとして管理・制限したい」 | 組織ポリシー（レジストリ）で機能を一括制御。社内配布用インストーラー付き |
| 「経費精算・請求配賦のために、部署ごとの利用量が欲しい」 | 期間（今日／7日／30日／今月／先月）で集計し CSV 出力 |

## 3. 主な機能

### 3.1 利用枠の表示（個人）
- **Codex（ChatGPT）**：5時間枠・週間枠の残り％、リセット時刻、プラン種別。
- **Claude**：5時間枠・週間枠の残り％（Claude Desktop の記録から）。
- タスクバーのボタンに「上段 Codex・下段 Claude の残り％」を常時表示。タスクトレイのアイコン表示にも切替可能。
- 残りが少なくなったら Windows 通知（しきい値は 10/20/30/50% から選択）。
- **リセット通知（任意）**：枠がリセットされたら Windows 通知。「残りが少なかったときだけ」「毎回」から選べます。
- **フレンドの残り枠（任意）**：OneDrive などの共有フォルダを使って、友だち・同僚と Claude・Codex の残り％とリセット時刻を見せ合えます。共有するのは表示名と残り枠だけ（メールアドレス・作業内容は共有しません）。

### 3.2 使用量の履歴・詳細ログ
- **履歴グラフ**：Claude Code・Codex の日別トークン（7日分）。
- **詳細ログ**：セッションごとに「誰が・いつ・どの経路で・何トークン使ったか」。
  - Codex：入力・キャッシュ済み入力・出力・推論・合計。
  - Claude Code：入力・出力・キャッシュ読み取り・作成（メッセージID＋リクエストIDで重複除去）。
- **依頼文の一覧**：「誰が何を入力したか」を一覧・全文で確認（オフにもできます）。

### 3.3 チーム機能（マスター／一般ユーザー）
- **マスター（導入者）**が、メンバーをメールアドレスで登録し、招待メールを送付。
- メンバーが招待コードを貼り付けて同意すると、そのPCの利用量が**自動で集計**されます（登録メールで Claude Code・Codex にログインしていれば承認操作も不要）。
- **管理画面**でメンバーごとに確認できるもの：
  - 日別の合計、日別・モデル別の内訳
  - API 換算の金額（単価×トークン×為替）と、登録した契約プランの月額
  - Codex・Claude の残り枠
  - セッション、依頼文（本人が同意した範囲まで）
  - 各PCの承認状況・チーム確認コード
- 期間集計と CSV 出力に対応。

### 3.3B 経営ダッシュボードとAI提案（上層部向け）
- **AI活用ダッシュボード**：活用率・AI力ランキング・「サマリー・次の一手」・日別トークン・API換算コストを1画面で。
- **AIに提案してもらう（任意・既定オフ）**：集計サマリーを Claude に渡し、現状サマリーと次の一手を自動生成。マスターのAPIキーで動作し、依頼文の本文は送りません（組織ポリシーで無効化可）。
- **定期レポート（任意・既定オフ）**：毎日／毎週（曜日指定）／毎月で、時刻（時：分）を決めて上の提案を自動生成。できあがるとタスクトレイに通知し、クリックで開けます。
- **スタートライン（顧客別の基準値・任意・既定オフ）**：顧客のAI導入段階（導入前／試験導入／一部活用／全社活用）に合わせて目標を設定。KPI・AI力ランキング・サマリーが「目標に対する達成度」で表示され、次に目指す段階まで提案します。
- スコアは活用の量・頻度・幅の目安で、作業の質・人事評価そのものではありません。

### 3.4 セキュリティ・企業導入
- **暗号化**：メンバーの報告はチーム公開鍵で暗号化（RSA-3072 ＋ AES-256 ＋ HMAC-SHA256）。マスター以外は読めません。
- **改ざん・なりすまし対策**：各PCの署名鍵、チーム確認コード照合、報告の差し戻し・未来日時の検知、権限昇格の防止。
- **プライバシー**：共有範囲は本人の同意が前提。閲覧範囲は3段階、組織ポリシーで上限を設定可能。
- **組織ポリシー**：チーム機能・依頼文表示・書き出し・ログイン時起動などを、レジストリで一括制御。
- **配布**：管理者権限不要のインストーラー。無音インストール（`/quiet`）で一括配布も可能。
- **監査資料**：導入時のセキュリティ審査に使える仕様書・セキュリティ資料を同梱。

## 5. 導入のしかた

### 5.1 個人で使う
1. `AI-Usage-Bar-Setup-0.1.0.exe` をダブルクリック。
2. インストール先（`%LOCALAPPDATA%\Programs\AI Usage Bar`）とオプション（デスクトップのショートカット等）を確認して「インストール」。
3. スタートメニューまたはタスクバーのボタンから起動。

### 5.2 チームで使う（マスター）
1. 「チーム」タブ →「チームを作成する」。チーム名・共有フォルダ・パスフレーズを設定。
2. 「メンバーを追加（メール）」でメンバーのメールアドレスを登録。
3. 表示される招待メールを、メールアプリ・Gmail・Slack で送付。
4. メンバーが参加したら、管理画面で利用量を確認。

### 5.3 会社で一括導入（情シス）
1. 組織ポリシー（`HKLM\SOFTWARE\Policies\AIUsageBar`）を配布して機能を制御。
2. インストーラーを配布ツールで無音インストール（`AI-Usage-Bar-Setup-0.1.0.exe /quiet`）。
3. 同梱の「仕様書・セキュリティ資料」でセキュリティ審査に対応。

## 6. 料金・費用の見える化

AI Usage Bar は、利用「量」と「費用」の両面を表示します。

- **プラン月額**：メンバーごとに契約プラン（ChatGPT Pro、Claude Max 等）と月額を登録し、実費として合算。
- **API 換算（目安）**：日別・モデル別のトークン数に単価（100万トークンあたりの米ドル）と為替を掛けて概算。
  - Claude のモデルは公式料金を初期設定。OpenAI のモデルは料金表を見て入力。
  - キャッシュ読み取り・キャッシュ作成（5分／1時間）も区別して計算。
- ※ API 換算は「使った量を API で買った場合の目安」で、サブスクリプションの実際の請求額とは異なります。

## 9. よくある質問

**Q. アプリはインターネットに接続しますか？**
A. 既定では接続しません。PC 内の記録を読むだけで、チーム機能も社内の共有フォルダのみを使います。唯一の例外は、上層部向けの任意機能「AI提案」を有効にした場合で、そのときだけマスターのAPIキーで Anthropic API に集計サマリー（数値と傾向。依頼文の本文は含みません）を送信します。組織ポリシーで無効化できます。

**Q. 会話の内容やパスワードは保存・送信されますか？**
A. しません。保存するのは使用量・時刻・識別子などです。依頼文は「詳細ログ」で表示できますが、書き出したとき以外はファイルに残しません。チームで依頼文を共有するかは、本人が同意した場合だけです。

**Q. マスターは、メンバーの許可なく作業内容を見られますか？**
A. 見られません。共有範囲は「マスターの設定・本人の同意・組織ポリシー」のうち最も狭い範囲まで。本人はいつでも範囲を狭めたり退出でき、退出すると報告は削除されます。

**Q. コード署名はありますか？**
A. 本バージョンは未署名です。社内配布の際は、組織のコード署名証明書での署名、または AppLocker / WDAC への登録を推奨します（同梱の SHA-256 で改ざん確認できます）。

**Q. ChatGPT や Claude の通常チャットも集計されますか？**
A. いいえ。対象は Claude Code・Codex の記録と、Claude Desktop の利用枠です。通常チャットは PC に記録が残らないため対象外です。
