AI Usage Bar 0.1.0（Windows版）— 他のPCでの確認手順

導入前に、実際に使うPCで次の順に確認してください。所要時間は5〜10分です。
うまくいかない項目があれば、⑨の「仕様・セキュリティ情報」を書き出して配布元に送ってください
（会話本文・依頼文・メールアドレスは含まれません）。

────────────────────────────────
① 受け取ったファイルの確認
────────────────────────────────
□ Slack 等から zip をダウンロードし、右クリック →「すべて展開」で展開した
  （zip の中の exe を直接ダブルクリックしない）
□ PowerShell で次を実行し、表示された値が SHA256.txt と一致した
    Get-FileHash .\AI-Usage-Bar-0.1.0-windows-unsigned.exe -Algorithm SHA256

────────────────────────────────
② 起動
────────────────────────────────
□ exe をダブルクリックして起動した
  ※「WindowsによってPCが保護されました」と出た場合は、配布元が確かなときだけ
    「詳細情報」→「実行」。会社のPCで実行自体がブロックされる場合は、
    情報システム部門の許可（署名・許可リスト登録）が必要です。
  ※「.NET Framework が古いため起動できません」と出た場合は、Windows Update で
    .NET Framework 4.8 を入れてから再度起動してください。
□ タスクバーに AI Usage Bar のボタンが出た（上段 Codex、下段 Claude の残り％）
□ ボタンをクリックすると画面が開き、もう一度クリックすると収納された

────────────────────────────────
③ 推奨の場所へ移動（常用する場合）
────────────────────────────────
□ 設定 →「推奨の場所へ移動…」→ OK で、起動し直された
□ 移動後、設定の「実行場所」が %LOCALAPPDATA%\Programs\AI Usage Bar\ になった

────────────────────────────────
④ 利用枠（使っているサービスだけで可）
────────────────────────────────
□ Codex：残り％とリセット日時が表示された
  「Codex CLIが見つかりません」→ Codex アプリか Codex CLI を入れて、ChatGPT でログイン
  「ChatGPTアカウントでのCodexログインが必要です」→ Codex でログインし直す
  「Codex CLIが古いため…」→ Codex を最新版に更新
□ Claude：5時間・週間の残り％が表示された
  「Claudeアプリの保存履歴を読み取れません」→ Claude Desktop でログインし、使用状況を一度開く
  灰色の「—」→ Claude Desktop を起動して15分ほど待つ

────────────────────────────────
⑤ 履歴・詳細ログ（Claude Code・Codex を使っている場合）
────────────────────────────────
□ 履歴タブに7日分のグラフが出た
□ 詳細ログタブで、今日のセッションと「入力の一覧（誰が・何を）」が出た
□ 入力者が「Windowsユーザー名@PC名」、アカウントがログイン中のメールになっている

────────────────────────────────
⑥ 設定
────────────────────────────────
□ Codex の更新間隔、Claude・作業ログの確認間隔を変更できた
□ 画面の拡大率が 100% 以外のPCでも、文字や枠が崩れていない

────────────────────────────────
⑥-2 チーム機能（使う場合）
────────────────────────────────
□ マスター：「チームを作成する」でチームを作り、表示されたチーム確認コード（32桁）を控えた
□ 一般ユーザー：「チームに参加する」で共有フォルダを読み込み、マスターの控えの確認コードを入力して参加できた
□ 一般ユーザー：わざと1文字違う確認コードを入力すると、参加できないことを確認した
□ 一般ユーザー：「チーム」タブの「共有中の範囲」が、同意した範囲になっている
□ 一般ユーザー：「今すぐ報告」の後、「最終報告」の時刻が更新された
□ マスター：「チーム管理画面を開く」→ 承認待ちのPCを「確認する」で開き、「PC確認コード」が
  一般ユーザーの「チーム」タブの「このPCの確認コード」と一致したので承認し、表に利用量が出た
□ マスター：閲覧範囲を「依頼文まで」にしたメンバー（本人も同意）の「依頼文」タブに内容が出た
□ 一般ユーザーのPCで、他のメンバーの内容が見えないことを確認した

────────────────────────────────
⑦ タスクトレイ（任意）
────────────────────────────────
□ 画面右下「^」の中に Codex（四角）と Claude（丸）のアイコンがある
  常に表示するには：設定 → 個人用設定 → タスクバー → その他のシステム トレイ アイコン

────────────────────────────────
⑧ 企業ポリシーを使う場合（管理者）
────────────────────────────────
□ HKLM\SOFTWARE\Policies\AIUsageBar に値を配布し、アプリを再起動した
□ 設定画面に「組織のポリシーで管理されています」と表示され、該当機能が使えない

────────────────────────────────
⑨ 結果の送付
────────────────────────────────
□ 設定 →「仕様・セキュリティ情報を書き出す…」で保存した
□ うまくいかなかった場合は、そのファイルと、あれば %LOCALAPPDATA%\AIUsageBar\error.log を配布元に送った

────────────────────────────────
⑩ 終了・片付け（試用だけの場合）
────────────────────────────────
□ 画面下の「終了」で終了した
□ exe と %LOCALAPPDATA%\AIUsageBar を削除した
